    How this page reads the data

    Two endpoints, both on the private Cloud Run service. /v1/activity reads at most the sample size of rows from a recent-activity index whose row keys carry the complement of each event's receive time, so the newest entries come back from a bounded prefix read rather than a table scan. Index entries older than one hour are excluded on read as well as collected by the column family's max-age rule. Each entity is then read through its own row, so a record its account has hidden drops out of the list instead of being shown.

    Choosing a record calls /v1/current-state for that entity alone: one point read of one row.

    There is no chart here. A bounded sample of the newest entries is not a time series, and this page holds no history of its own, so a chart drawn from it would imply measurements that were never taken. Throughput, latency and resource charts are in Cloud Monitoring, which measures them.
